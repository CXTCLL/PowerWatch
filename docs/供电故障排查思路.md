# 供电故障排查思路

这份文档说明：拿到 PowerWatch 的数据之后，怎么一步步定位到具体环节。

---

## 第一步：分清 A 类还是 B 类

整个排查的分岔点只有这一个。判断错了，后面全白做。

| | 表现 | 含义 |
|---|---|---|
| **A 类 · 真断电** | 屏幕黑、机器重启或关机、外设掉线、风扇停转 | 供电真的断了，电池没接住 |
| **B 类 · 假断电** | 机器一直在跑，只是充电图标闪、亮度抖、弹出"电源已断开" | AC 检测信号丢了，功率其实没断 |

在日志里对应的证据：

- A 类通常会伴随 `Kernel-Power 41` 事件，或日志在某一刻戛然而止（`recovered_*.csv` 里能捞到）
- B 类会出现密集的 `AC_LOST` / `AC_BACK` 成对记录，而机器从头到尾没重启

---

## 第二步：看电压、电流、交流位三列的配合

打开 `event_*.csv`，找到标了 `<== EVENT` 的那一行，看断点附近：

```
电压塌下去 + 电流变成明显正值   → 功率通路在掉：DC 座焊点、输入保险、电源路径 MOS
电压不动 + 电流始终为 0        → 检测回路误判：ACDET 分压、充电 IC
电压小幅跌落 + 电流随负载起伏   → 接触电阻型，事件频率会随负载上升
```

**电流这一列是分水岭。** 只看 `交流在线` 会被骗——标志位误判和真实断电，在那一列上长得一模一样。而电池电流说了算：功率真的切走了，电流必然出现一个明显的正值；电流纹丝不动，说明适配器一直在供电，只是系统以为自己被拔了。

推理很简单：笔记本电脑在运行，就一定在耗电。如果电池没在放电，电只能来自适配器。

## 一个真实案例：一天 6 次「假断电」

某台机器报告"插着电偶尔断电一秒又恢复"。挂上工具跑了一天，捕获到 6 组事件，全都长这样：

```
时间          电池电压   电池电流   交流   状态
13:42:18.511  16575mV    0mA        1     0x0001   ← 正常
13:42:18.605  16575mV    0mA        0     0x0000   ← 事件开始
   ...（持续 10 个采样）
13:42:19.511  16575mV    0mA        0     0x0000
13:42:19.618  16575mV    0mA        1     0x0001   ← 恢复
```

**电压一毫伏没动，电流一直是 0，持续 1.0 秒。**

如果是真的断电，切换瞬间电流会从 0 跳到几百毫安以上，电压也会出现明显跌落。两者都没有，说明功率根本没转移，适配器一直在供电。

再往前查负载：这 6 次发生时 CPU 占用从 8% 到 38% 都有，**与负载无关**——进一步排除了接触电阻（接触电阻的压降随电流增大，事件频率会跟着负载走）。

同一天还有一次不一样：

```
18:12:05.4  16221mV  4295mA  ac=0 dis=1  0x0002   ← 真在放电，约 69W
18:12:06.3  16221mV     0mA  ac=0 dis=0  0x0000
18:12:07.6  16197mV          ac=1        0x0001
```

这次放电电流 4.3 安，是真的切到电池供电了，持续 3.4 秒。

**同一台机器、同一天，工具能区分出两种性质完全不同的事件**——这就是为什么必须记录电流，而不只是记录"有没有断电"。

结论：前五次是 EC 的 AC 检测回路误判，功率通路完好；第六次是真实的供电中断。两者的维修方向完全相反。

## 第三步：板内通路的分段定位

DC 座之后的串联链路，任何一段接触电阻变大或瞬时开路，表现都一样：

```
DC 座焊点 → 输入保险/TVS → 输入滤波 → 背靠背 MOS → 充电 IC(ACOK/ACDET) → 系统轨/电池
```

用万用表做**压差测量**，不猜绝对电压，只看同一元件两端的压降——这个方法跟具体机型无关。

| 测点 | 空载 | 满载 | 异常含义 |
|---|---|---|---|
| DC 座引脚 → 保险输入端 | < 30 mV | < 100 mV（> 200 mV 异常） | 引脚虚焊或焊盘裂纹 |
| 输入保险两端 | < 20 mV | < 80 mV | 熔丝微裂、端帽虚焊 |
| 背靠背 MOS 的 D-S | — | < 100 mV | MOS 导通电阻退化 |

**关键工具要求**：万用表必须带 MAX/MIN 记录功能。偶发故障是毫秒级的，普通静态测量永远抓不到，只能靠仪表自己记峰值。

---

### 三个高频嫌疑

### 输入保险微裂

贴片保险的失效往往不是彻底烧断，而是端帽与陶瓷体之间的焊层出现微裂纹，变成一个随电流和温度变化的可变电阻。电流脉冲来时热胀微开，冷却后重新接通——正好表现为"偶发、一秒、与负载相关"。

这类故障**静态通断测试和目视检查都查不出来**。

### DC 座焊盘环状裂纹

长期插拔受力后，焊点产生肉眼不可见的环状裂纹。板子轻微形变（合盖、搬动、掌托受力）就会瞬间断开。

判断方法：一边看电压一边按压机身不同区域，能复现就基本确认。

### ACDET 分压电阻虚焊

检测脚电压在阈值边缘游走时，EC 每抖一次就报一次拔插，而充电 IC 的去抖时间恰好是几百毫秒到一秒。

虚焊多发生在分压抽头那一侧。

## 第四步：排除误报

PowerWatch 的数据也可能骗人，几种常见情况：

| 现象 | 真相 |
|---|---|
| 事件前一秒电压还在 16.8V，断后掉到 16.4V | 电池**表面电荷弛豫**，充电末段被抬高的电压自然回落，不是故障 |
| 电量 100% 时反复"未充电" | 电池养护模式在 55–60% 或 100% 阈值附近来回切，属正常策略 |
| 满电静置时电流显示 0 mA | 系统直接吃适配器，电池支路确实没有电流 |

---

## 第五步：送修怎么说

板级偶发故障最怕被判定"无故障退回"。不要描述症状，直接给测量要求：

> 机器在纯交流供电下无规律出现 1 秒左右的供电中断，适配器与线缆已更换、插座已更换，问题依旧。请检测：① DC 座引脚与焊盘的负载压差；② 输入保险两端压差；③ 电源路径 MOS 的 D-S 压降；④ 充电 IC 的 ACOK/ACDET 引脚电平是否有瞬时跌落；⑤ 电池连接器接触电阻。建议用带 MAX/MIN 记录的万用表做动态测量，静态通断测试查不出这类故障。

附上 `events.csv` 的时间戳和故障发生时的录像。

## 安全提示

通电测量有短路和触电风险：

- 拆后盖前先断开适配器
- 只用单手持表笔，另一只手不要碰机身
- 表笔尖要细，落点前确认不会碰到相邻焊盘
- 探头用胶带固定后再通电，不要边通电边找位置
- **绝对不要在通电状态下插拔任何排线**
- 机器在保就直接送修，不要自己动手
