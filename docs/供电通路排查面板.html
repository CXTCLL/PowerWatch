板内供电路径排查：DC 座之后

排查范围收窄到机身内部。从 DC 座焊点开始，沿输入保险、滤波、背靠背 MOS、充电 IC 的 ACOK 检测回路，一直到系统主轨与电池，逐节点用压差法定位断点。

板内通路与可测节点

这七个环节是串联的，任何一处接触电阻变大或瞬时开路，都会在系统侧表现为供电中断。下图标出六个测点：Δ 为跨接压差，V 为对地电压。

先说方法论。这条链路上有两类故障，表现完全一样但位置差很远：功率通路断了（焊点、保险、MOS）和检测回路误判（ACOK 分压、充电 IC）。区分它们只需要两个表笔——同时盯着 V1（输入电压） 和 ACOK 电平：中断瞬间如果 V1 塌了，是功率通路；如果 V1 稳如磐石而 ACOK 掉了，是检测回路。这一刀切下去，后面就不用乱猜了。
2

第 0 步：确认中断发生在哪一层

不拆机也能做，用来给后面的测量定方向。

中断发生时盯三样：屏幕是否黑、风扇是否停、外接鼠标灯是否灭。三样全断 → 功率通路（Δ1–Δ3 区间）；三样都正常只是图标闪 → 检测回路（ACOK / 充电 IC）。这个结论决定后面优先测哪一段。

如果是功率中断但机器没死，说明电池顶住了，此时电池连接器也在嫌疑范围内——因为那一瞬间是它在承担全部电流。

管理员 PowerShell，每 200ms 采样一次，只在变化时写日志到桌面 ac_watch.txt。

$log = "$env:USERPROFILE\Desktop\ac_watch.txt"
$last = $null
while ($true) {
  $b = Get-CimInstance Win32_Battery
  $s = "$($b.BatteryStatus)|$($b.EstimatedChargeRemaining)"
  if ($s -ne $last) {
    "{0}  status={1}  batt={2}%" -f (Get-Date -Format "yyyy-MM-dd HH:mm:ss.fff"), $b.BatteryStatus, $b.EstimatedChargeRemaining | Add-Content $log
    $last = $s
  }
  Start-Sleep -Milliseconds 200
}

BatteryStatus 为 1 表示放电，2 / 3 / 6 / 7 表示挂在交流上。看到 2→1→2 的来回跳，就是 AC 检测在抖。

powercfg /batteryreport /output "$env:USERPROFILE\Desktop\battery.html"

满充容量低于设计容量 70% 时，电池在切换瞬间的输出电压会塌陷，本来一次正常的切换会被放大成整机掉电。这一项决定后面要不要把电池连接器列为主嫌。

3

第 1 步：不拆机的定向触发

在监听窗口开着的情况下做。能复现比能测量更重要——复现不了，万用表夹上去也是白等。

合盖再打开；单手抬机身一角使底壳轻微形变；在键盘右侧和转轴附近用指腹缓慢加力。目的是让主板产生微米级弯曲。能复现 → 焊点类故障（DC 座引脚、保险端帽、MOS 引脚），属于板级虚焊，热风枪补焊即可解决。

用指关节轻敲底壳的不同区域，每次一个区域，间隔 30 秒：左后（DC 座附近）、中部（充电 IC 与 MOS 区）、右下（电池接口区）。敲到某个区域才复现 → 该区域有虚焊或连接器接触不良，直接把范围缩到几平方厘米。

Fn+Q 依次切到安静 / 均衡 / 野兽，每档跑 15 分钟，记录每档的中断次数。频率随功率上升 → 串联电阻型故障（保险端帽微裂、焊点氧化、MOS 导通电阻升高），因为压降随电流线性放大。频率与功率无关 → 更偏检测回路或 BMS。

4

第 2 步：开盖后的压差测量

到这一步才需要工具。核心原则：不猜绝对电压，只看同一元件两端的压差。压差法对接触电阻最敏感，也不受具体机型电压设计的影响。

安全前置。通电测量有短路和触电风险，以下几条不是建议是必须：断开适配器再拆后盖；拆完先摸一下金属机箱放静电；测量时只用单手持表笔，另一只手不要碰机身；表笔尖必须细（推荐针式探头），落点前先确认不会同时碰到相邻焊盘；探头用胶带临时固定后再通电，不要边通电边找位置；绝对不要在通电状态下插拔任何排线。若机器在保，直接跳到第 5 节，不要自己动手。

正常
空载 < 20mV，满载 < 80mV
异常
压差随负载明显上升，或 MAX 值跳到 1V 以上
含义
熔丝微裂或端帽虚焊。这类故障的典型特征就是"偶发、一秒钟、与负载相关"——熔丝在电流脉冲下热胀微开，冷却后重新接通，肉眼和静态通断测试都查不出来
这一项是本次症状最匹配的候选之一。贴片保险的失效往往不是彻底烧断，而是端帽与陶瓷体之间的焊层出现微裂纹，表现为一个随温度、电流变化的可变电阻。
测法
跨接在电源路径 MOS 的 D-S 之间（通常是 DC 座与充电 IC 之间的两颗并排 MOS）
正常
导通时 < 100mV
异常
压差异常大，或中断瞬间跳到数伏
含义
MOS 导通电阻退化或栅极驱动异常。栅极电压不足会让 MOS 工作在放大区，压降随电流急剧上升，触发后级欠压保护
测法
找到充电 IC 的 ACOK（或 ACDET）引脚，对地测电压，同时用 MAX/MIN 模式长期记录
正常
稳定停在阈值之上，全程无跳变
异常
在阈值附近游走，或出现掉到 0 的瞬时脉冲
含义
ACDET 分压电阻虚焊或阻值漂移。检测脚电压在阈值边缘抖动时，EC 每抖一次就报一次"拔插"，而充电 IC 的去抖时间正好是几百毫秒到一秒
把 M1 的 V1 和这一项同时测：V1 掉了 → 功率通路；V1 不动而 ACOK 掉了 → 检测回路。这一个对照就能把七段链路砍成两半。分压电阻通常是两颗高阻值贴片电阻，一端接输入电压，一端接地，中间抽头进 IC——虚焊多发生在抽头那一侧。
测法
测电池连接器两端的压差，以及系统主轨在中断瞬间的跌落幅度
异常
切换瞬间主轨跌到后级欠压阈值以下
含义
电池排线接触电阻过大或 BMS 保护跳变。AC 掉线那一瞬全部电流由电池承担，接触不良就会把一次正常的电源切换放大成整机掉电

如果 M1–M4 全部正常而故障依旧，这一项就是最后的嫌疑。把电池排线重新插拔一次、清洁触点，观察 48 小时。

送修时要说的话

板级偶发故障最怕被判定"无故障退回"。与其描述症状，不如直接给测量要求和判据。

"机器在纯交流供电下无规律出现 1 秒左右的供电中断，适配器与线缆已更换、插座已更换，问题依旧，范围已排除到机身内部。请做以下检测：① DC 座引脚与焊盘的负载压差；② 输入保险两端压差（重点，怀疑熔丝微裂或端帽虚焊）；③ 电源路径 MOS 的 D-S 压降；④ 充电 IC 的 ACOK / ACDET 引脚电平是否有瞬时跌落；⑤ 电池连接器接触电阻。建议用带 MAX/MIN 记录的万用表做动态测量，静态通断测试查不出这类故障。"

附上 ac_watch.txt 里的时间戳、以及故障发生时拍的视频。有客观时间点，对方就不好用"没测出来"推回来。

按可能性从高到低，需要准备的件是：输入保险（几毛钱，但工时占大头）、DC 座组件、电源路径 MOS、充电 IC。前两项属于常规板级维修，第三、四项需要 BGA 或 QFN 返修能力，报价会明显上一个台阶。如果检测下来指向主板多点为虚焊，换整块主板的性价比可能更高。

送修前先在官网用 SN 查整机与电池各自的保修期，备份数据并退出账号，取机时核对工单上写明的更换部件。
